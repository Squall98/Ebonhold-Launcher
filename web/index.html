            Le jeu est repassé en anglais après une mise à jour du serveur
            

              
Une mise à jour officielle remplace des fichiers du jeu. Au démarrage, le launcher s'en rend compte et réapplique tes réglages (un message s'affiche sur l'Accueil).

              
Sinon : ferme le jeu, onglet Français, puis Appliquer.

            

          

          

            « ebonhold.dll n'est pas conçu pour s'exécuter sous Windows », ou le jeu reste bloqué sur « PLAYING »
            

              
Ce message vient du launcher officiel du serveur, pas de ce launcher-ci.

              
Lance plutôt le jeu avec le bouton Jouer d'ici : il ouvre directement Wow.exe.

            

          

          

            Le pack FR ne s'installe pas
            

              
Place disque : le pack pèse 2,6 Go. Il faut environ 2,7 Go libres sur le disque du jeu, et autant sur C: pendant le téléchargement (si le jeu est sur C:, compte 5,5 Go).

              
Antivirus : il peut bloquer le téléchargement. Autorise le launcher, puis relance l'installation depuis l'onglet Français.

              
Toujours bloqué ?  en joignant le journal.

            

          

          

            Mon antivirus (ou Windows) bloque le launcher
            

              
Le launcher est un petit programme communautaire, non signé : Windows et certains antivirus s'en méfient. Son code est public sur GitHub.

              
Écran bleu de Windows : « Informations complémentaires », puis « Exécuter quand même ».

              
Antivirus : ajoute une exception pour le dossier du launcher.

            

          

          

            Un addon n'apparaît pas en jeu
            

              
À l'écran de choix du personnage, clique sur AddOns (en bas à gauche) et coche « Charger les AddOns obsolètes ».

              
Puis ferme complètement le jeu et relance-le : un /reload ne suffit pas pour un nouvel addon.

            

          

          

            Le launcher ne trouve pas mon jeu
            

              
Onglet Réglages, puis « Détecter automatiquement ». Si rien n'est trouvé, accepte la recherche sur ton PC, ou choisis le dossier à la main avec « Changer… » (le dossier qui contient Wow.exe).

            

          

          

            Comment désinstaller ?
            

              
Un addon : clique dessus dans l'onglet Addons, puis « Désinstaller ».

              
Le français : préréglage « Tout en anglais », puis Appliquer. Le pack FR reste dans Data\frFR : supprime ce dossier pour récupérer la place.

              
Le launcher : supprime son dossier, et si tu veux ses réglages (voir la question suivante).

            

          

          

            Où sont mes réglages ?
            

              
Les réglages du launcher et son journal sont dans %APPDATA%\EbonholdLauncher (colle ce chemin dans l'Explorateur).

              
Les addons sont dans le dossier du jeu, sous Interface\AddOns : bouton « Dossier AddOns » dans l'onglet Addons.

            

          

        


        
        

          

            
            
            
            
            
            
          

          

            

              
L'accueil

              
              
    
                
  • Jouer vérifie tout avant de lancer le jeu : le français, les mises à jour d'addons, un jeu déjà ouvert. S'il trouve un souci, il propose « Corriger et jouer ».
    • 
                
  • Les quatre cartes résument l'état du jeu, du français, des addons et du launcher. Un bouton apparaît quand il y a quelque chose à faire.
    • 
                
  • Nouveautés : les dernières notes de version des addons.
    • 
              

              
            

            

              
Les addons

              
              
    
                
  • Installer en un clic ; les mises à jour aussi, ou toutes d'un coup avec « Tout mettre à jour ».
    • 
                
  • Les packs regroupent des addons qui vont ensemble (Récolte, Métiers…).
    • 
                
  • Recherche, catégories, et trois affichages : cartes, liste, tableau.
    • 
                
  • Clique sur un addon pour voir sa fiche, son historique, et le désinstaller.
    • 
              

              
            

            

              
Le français

              
              
    
                
  • Choisis un préréglage, ou règle chaque ligne en FR ou EN.
    • 
                
  • Recommandé : tout en français, sauf les noms Ebonhold (echoes, Soul Tree, affixes), gardés en anglais.
    • 
                
  • Le jeu de base, les voix et les sorts Blizzard en français demandent le pack FR (2,6 Go) : le launcher le télécharge pour toi.
    • 
                
  • Ferme le jeu, puis Appliquer. Après une mise à jour officielle, le launcher réapplique tes réglages tout seul.
    • 
              

              
            

            

              
L'aide

              
              
    
                
  • Signaler un bug ou proposer une idée : décris en quelques phrases et ajoute des captures. Tu reçois un numéro à citer sur le Discord.
    • 
                
  • Le journal du launcher peut être joint : il aide à comprendre ce qui s'est passé.
    • 
                
  • Les questions fréquentes règlent les soucis les plus courants.
    • 
              

            

            

              
Les réglages

              
              
    
                
  • Dossier du jeu : détection automatique, recherche sur ton PC (avec ton accord), ou choix à la main.
    • 
                
  • Zoom : agrandis ou réduis tout le launcher (aussi avec Ctrl + molette).
    • 
                
  • À propos : version du launcher et source du catalogue.
    • 
              

              
            

            

              
L'assistant de démarrage

              
              
    
                
  • Au premier lancement, trois étapes : trouver le jeu, choisir la langue, choisir des packs d'addons.
    • 
                
  • Tu peux le passer, et le relancer quand tu veux depuis les Réglages.
    •
